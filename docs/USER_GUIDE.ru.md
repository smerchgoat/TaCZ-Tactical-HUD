# Руководство пользователя

[English](USER_GUIDE.md) · **Русский**

## Требования

| Компонент | Версия | Обязателен |
|---|---|---|
| Minecraft | 1.20.1 | да |
| Forge | 47.x | да |
| [TaCZ] Timeless and Classics Zero | 1.1.8 и новее | да |
| Cloth Config API (Forge) | 11.x | нет: нужен только для меню настроек в игре |

Мод только клиентский: на сервер его ставить не нужно, а играть с ним можно на любом сервере с TaCZ.

## Установка

1. Скопируйте `tacz_tactical_hud-1.20.1-0.1.0-alpha.jar` в папку `mods/`.
2. Убедитесь, что там же лежат TaCZ и, при желании, Cloth Config.
3. Запустите игру и возьмите в руки любое оружие TaCZ.

## Как открыть настройки

- **Mods → TaCZ Tactical HUD → Config** (кнопка доступна, если установлен Cloth Config);
- или назначьте клавишу: **Настройки → Управление → TaCZ Tactical HUD → «Открыть настройки HUD»**.

Без Cloth Config настройки редактируются в файле `config/tacz_tactical_hud-client.toml`. Изменения из меню применяются сразу, правку файла вручную лучше делать при закрытой игре.

## Настройки

### Общие (`[general]`)

| Параметр в меню | Ключ в файле | По умолчанию | Что делает |
|---|---|---|---|
| Скрывать здоровье и броню | `HideHealthAndArmor` | да | Прячет ванильные сердца и броню, пока видна панель (она их показывает сама) |
| Скрывать хотбар | `HideHotbar` | нет | Прячет хотбар и всплывающее название выбранного предмета |
| Скрывать опыт | `HideExperience` | нет | Прячет шкалу опыта и цифру уровня |
| Скрывать еду | `HideFood` | нет | Прячет шкалу сытости |

Всё скрытое возвращается, как только вы убираете оружие.

### Профили «Первое лицо» (`[first_person]`) и «Третье лицо» (`[third_person]`)

У каждого вида камеры свой набор параметров. В третьем лице по умолчанию панель стоит у бедра персонажа, правый край уходит вглубь. В первом лице панель правее оружия, и наоборот: левый край уходит к мушке, правый ближе к экрану.

| Параметр | Ключ | Пределы | 1-е лицо | 3-е лицо | Что делает |
|---|---|---|---|---|---|
| Включён | `Enabled` | да/нет | да | да | Показывать панель в этом виде; если выключено, остаётся классический HUD TaCZ |
| Размер GUI | `GuiScale` | Авто, x1–x4 | Авто | Авто | Авто — размер от высоты экрана; xN — как при масштабе интерфейса N |
| Положение по горизонтали | `AnchorX` | 0–100% | 72% | 70% | Где по ширине экрана центр панели |
| Положение по вертикали | `AnchorY` | 0–100% | 62% | 62% | Где по высоте экрана центр панели |
| Масштаб | `Scale` | 0.25–4.00x | 1.25x | 1.25x | Множитель размера |
| Угол поворота | `Yaw` | −60…60° | −18° | 18° | «+» отодвигает правый край, «−» — левый |
| Угол наклона | `Tilt` | −45…45° | −6° | −6° | «−» отодвигает верхний край |
| Угол обзора перспективы | `Fov` | 10–110° | 40° | 40° | Меньше — перспектива площе, больше — сильнее «рыбий глаз» |
| Сила инерции | `SwayStrength` | 0–3.00 | 1.00 | 1.00 | Насколько панель отстаёт от поворота камеры; 0 — без инерции |
| Непрозрачность фона | `BackgroundOpacity` | 0–100% | 72% | 72% | Тёмная подложка панели |

Каждый ползунок можно сбросить кнопкой **Reset** справа.

**Советы по настройке**

- Хотите плоский HUD без 3D — поставьте `Yaw` и `Tilt` в 0.
- Панель перекрывает персонажа — увеличьте `AnchorX` или уменьшите `Scale`.
- На ультрашироком мониторе удобнее `GuiScale = x2` или `x3`: размер перестанет зависеть от высоты окна.
- Укачивает — уменьшите `SwayStrength` или поставьте 0.

## Гранаты и аптечки: теги предметов

Счётчики считают предметы из двух тегов:

| Тег | По умолчанию |
|---|---|
| `tacz_tactical_hud:grenades` | `splash_potion`, `lingering_potion`, `snowball`, `egg`, `fire_charge` |
| `tacz_tactical_hud:medkits` | `golden_apple`, `enchanted_golden_apple` |

Добавить свои предметы (например, гранаты или бинты из другого мода) можно датапаком:

`data/tacz_tactical_hud/tags/items/medkits.json`
```json
{
  "replace": false,
  "values": [
    { "id": "firstaid:bandage", "required": false }
  ]
}
```

`"required": false` не даёт тегу сломаться, если мода нет. `"replace": true` полностью заменяет список по умолчанию.

## Частые вопросы

**Панели нет.**
Проверьте по порядку:
1. в руке оружие TaCZ, а не патроны или обвес;
2. в настройках TaCZ включён HUD оружия;
3. для текущего вида камеры профиль `Enabled = да`;
4. вы не в режиме наблюдателя.

**В первом лице виден старый HUD TaCZ.**
Профиль «Первое лицо» выключен — включите его.

**Почему в оранжевой ячейке «--»?**
Это оружие питается прямо из инвентаря: магазина нет, запасных магазинов тоже.

**Почему запас показывает ∞?**
Вы в креативе, у оружия бесконечный запас или в инвентаре креативный ящик патронов.

**Совместим ли с шейдерами, Shoulder Surfing и другими модами HUD?**
Панель рисуется обычным оверлеем Forge поверх всего, шейдеры её не затрагивают. С Shoulder Surfing работает профиль третьего лица. Моды, которые тоже прячут или двигают ванильный HUD, могут конфликтовать с переключателями скрытия — тогда отключите их у одного из модов.

**Влияет ли на производительность?**
Почти нет: один проход по инвентарю за кадр и несколько десятков прямоугольников. Ёмкость магазина и запас пересчитываются не чаще раза в тик.

## Если что-то сломалось

Приложите к сообщению об ошибке:
- `logs/latest.log` (или `crash-reports/…`);
- версии Minecraft, Forge, TaCZ и аддона;
- список модов;
- файл `config/tacz_tactical_hud-client.toml`;
- скриншот и что вы делали в тот момент.
